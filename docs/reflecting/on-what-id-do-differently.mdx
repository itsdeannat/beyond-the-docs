# On what I'd do differently

I would have probably built SpecGate first, not SmartDoc. Although I learned good lessons building SmartDoc.

SpecGate works well because it has hardcoded rules that produce consistent output. But I learned this lesson the hard way with an earlier project (SmartDoc) that used an LLM to drive the analysis. But LLMS aren't really reliable because they're stateless and don't retain memories of previous conversations. So the LLM behind SmartDoc often gave different outputs for the same input. 

This taught me that tooling should be predictable and consistent.
